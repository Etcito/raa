# RAA: Render Anything Anywhere

An extensible WebGPU 3D engine in Rust (compiled to WebAssembly), built for games that ship tiny assets:
primitives are turned into polygons at load time instead of shipping baked meshes.

Status: bootstrap. MIT licence. Part of the Etcito open-source game stack (GameSaloon, gamesaloon-rollback, Royal Fiesta).
