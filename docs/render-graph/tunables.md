# Tunables triage table

First card of M4 (S56). This table defines "all parameters": a value is a parameter only when this table lists it as tunable. Every later promotion card implements exactly its own crate's rows and later cards update only the file:line cells, never the count.

## Header

WGSL search, run from the repository root:

`grep -rnE '^[[:space:]]*const[[:space:]]+[A-Za-z_][A-Za-z0-9_]*[[:space:]]*:[[:space:]]*(f32|u32|i32)[[:space:]]*=' crates/*/src --include='*.wgsl'`

Count on this tree: **265** lines, so the table holds exactly 265 rows with `row` = `wgsl` (63 tunable, 109 maths, 93 layout). They are followed by the missing-setting rows (`row` = `setting`), which are not counted: TAA inline values, the SSGI quality table, GTAO quality, ReSTIR GI CPU values and area-shadow CPU values (the other files of crates/raa-gi/src/parts/area_shadow write only frame data into their uniforms).

Classification:
- tunable: changes the look or quality of a pass that a catalog node drives and is not fixed by a layout. Constants of WGSL composed into forward-class or material variants (raa-shader, raa-brdf, raa-material, raa-transmission, raa-gi slots) are not promoted because the composer variant key has no pipeline constants; particle and liquid behaviour is scene content (Render graph rule 5).
- layout: codes, flags, enum ids, bit masks, workgroup and tile sizes, array or bit-width caps, encoding ranges, texture sizes and duplicates of another file's layout constants.
- maths: everything else (mathematical constants, epsilons, bounds, stand-in values, physical data).

Mechanism (M4 changes no GPU byte layout): `uniform` only for a value the CPU already writes into an existing uniform field (rebuild none); `define` for a value that sizes an array or drives a loop that must be unrolled (rebuild pipeline); `override` for every other tunable (rebuild pipeline). No WGSL constant of this tree sizes an array and is also tunable, so no row uses `define`.

Range: a range comes only from code or comments that state it, cited in the reason; otherwise `unstated`. The default of a tunable is its value without a trailing `u`, `i` or `f`. A hexadecimal value is never tunable. Keys are unique per node type, at most 32 characters.

## Families without tunables

- shadow: no WGSL constants; keeps its Setting parameters.
- fog: `raa_height_sky_distance_m` is maths (the stand-in distance of a sky pixel); keeps its Setting parameters.
- bloom: no WGSL constants; keeps its Setting parameters.
- grading: MID_GREY, LOG_STOPS and LOG_FLOOR are maths; keeps its Setting parameters.
- tonemap: AGX_MIN_EV, AGX_MAX_EV and ACES_PRE_SCALE are maths; keeps its Setting parameters.
- oit: OIT_MAX_LIMIT is layout (the per-pixel array cap, equal to the upper end of MAX_FRAGMENTS_RANGE in crates/raa-oit/src/feature.rs:40); keeps its Setting parameters.
